# Памятка по функциям metrika_updater.gs

## Токен Метрики — один раз при настройке

Токена в коде нет: файл лежит в публичном репозитории. Скрипт берёт его из свойств проекта.

1. Apps Script → **Настройки проекта** (шестерёнка слева) → **Свойства скрипта** → **Добавить свойство**.
2. Название: `METRIKA_TOKEN`, значение — OAuth-токен Метрики без кавычек. Сохранить.
3. Если токен где-то засветился, отзовите его на oauth.yandex.ru и запишите сюда новый.

Без свойства каждый запуск завершится ошибкой «Не задан токен Метрики», а ежемесячное письмо придёт с пометкой ⚠️.

| `metrikaZdorovenokNew` | Здоровенок — только новые месяцы |
| `metrikaZdorovenokFull` | Здоровенок — полная перезапись |
| `metrikaKosmetologiyaNew` | Косметология — только новые месяцы |
| `metrikaKosmetologiyaFull` | Косметология — полная перезапись |
| `metrikaKdlNew` | КДЛ — только новые месяцы |
| `metrikaKdlFull` | КДЛ — полная перезапись |

| `metrikaDinoFull` | Дино — полная перезапись |

### Если ежемесячный триггер оборвался

Обновление всех брендов идёт очередью: каждый бренд (а Клиника — каждый из 5 центров)
обрабатывается отдельной единицей. Подойдя к лимиту времени Apps Script (6 минут),
скрипт сохраняет прогресс и сам ставит триггер на продолжение через минуту.
Письмо с отчётом приходит один раз, когда очередь закончилась.

Если единица упала с исключением (сбой Google Sheets, ответ API не JSON, нет токена),
скрипт сразу пробует её ещё раз, а после двух неудач пропускает с текстом ошибки в письме.
Если в блоке источников упал хоть один из четырёх запросов, лист `metrika_sources`
за этот период не пишется — следующий запуск запросит его заново, без дыр в детализации.

| Функция | Что делает |
|---|---|
| `showMonthlyQueue` | Показать в логе, что осталось в очереди и сколько было попыток |
| `continueMonthlyUpdate` | Продолжить прерванное обновление вручную (обычно вызывается триггером сам) |
| `resetMonthlyQueue` | Сбросить залипшую очередь и удалить триггеры-продолжения |

## Директ (direct_updater.gs)

| Функция | Что делает |
|---|---|
| `directStomatologyNew` | Стоматология — только новые недели |
| `directStomatologyFull` | Стоматология — полная перезапись |
| `runWeeklyUpdate` | Все бренды — только новые недели (запускается триггером) |
| `createWeeklyTrigger` | Создать/пересоздать триггер (каждый понедельник в 8:00) |

## Когда что использовать

**New** — штатный запуск, докидывает только те месяцы, которых ещё нет в таблице. Запускай вручную если триггер не сработал.

**Full (все листы)** — если данные испорчены или нужно пересчитать всё с нуля. Удалит все листы бренда и запишет заново с 2025-01-01.

**SourcesFull / runAllSourcesFull** — для разовой миграции: перезаписывает только лист `metrika_sources`, добавляет колонку `parent` и строки с детализацией по соцсетям, мессенджерам и рекомендательным системам. Остальные листы (traffic, adv, pages) не трогает.

**createMonthlyTrigger** — запустить один раз при первоначальной настройке или если триггер пропал из Apps Script.

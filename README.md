# SEO Dashboard — dental.sadkomed.ru

Ежемесячный SEO-отчёт для руководства. Дашборд читает данные напрямую из Google Sheets и строит графики автоматически.

## Как это работает

```
Google Sheets (данные) → GitHub Pages (дашборд) → ссылка для руководства
```

Раз в месяц добавляешь новые строки в таблицу — дашборд обновляется сам.

## Структура Google Таблицы

Таблица называется `otchet_dentalsadkomed`. Три листа:

### Лист `positions` — позиции сайта
| date | top1 | top5 | top10 | top50 | traffic | pages |
|------|------|------|-------|-------|---------|-------|
| 04.06.2026 | 33 | 211 | 394 | 724 | 737 | 76 |

Данные берутся из CSV-выгрузки Кейсо. Строка с dental.sadkomed.ru.

### Лист `queries` — ключевые запросы
| date | query | position | frequency | page |
|------|-------|----------|-----------|------|

Данные берутся из Excel-выгрузки Кейсо (файл `dental.sadkomed.ru.organic.keys`).  
Колонки: Запрос → query, Позиция → position, Базовая частотность → frequency, Страница → page.  
Вставляются как есть, в том порядке как выгружается из Кейсо.

### Лист `ads` — реклама конкурентов
| date | domain | ads | queries | traffic | budget |
|------|--------|-----|---------|---------|--------|

Данные берутся из Google Таблицы Кейсо (лист "контекст").  
Бюджет вставляется как есть (с пробелами и ₽) — дашборд чистит сам.

## Что делать каждый месяц

1. Открыть Google Таблицу
2. В лист `positions` добавить одну строку с новыми данными
3. В лист `ads` добавить строки конкурентов (скопировать из таблицы Кейсо, добавить дату)
4. В лист `queries` добавить запросы из Excel Кейсо (добавить дату в первую колонку)
5. Открыть дашборд — данные обновятся автоматически

## Что умеет дашборд

- Метрики позиций с дельтой к прошлому месяцу (↑↓)
- Переключатель по месяцам — появляется автоматически при добавлении новых строк
- График динамики топ-позиций за все месяцы
- График органического трафика
- Таблица запросов с фильтром по позиции (топ 1 / 2 / 3), частотой и ссылкой на страницу
- Таблица конкурентов по рекламе с визуальными полосками бюджетов
- Кнопка "показать все запросы" (по умолчанию первые 15)

## Как обновить дашборд

1. Скачать файл `dental_seo_dashboard.html` из репозитория
2. Внести изменения
3. Загрузить обратно через GitHub → Add file → Upload files → Commit changes

GitHub Pages обновится автоматически через 1-2 минуты.

## Технические детали

- Дашборд — один HTML-файл, никаких зависимостей
- Данные читаются через Google Sheets CSV API (публичный доступ по ссылке)
- Графики — Chart.js 4.4.1
- Шрифты — Unbounded + Golos Text (Google Fonts)
- ID таблицы: `18_wK4ym4OvY5YuCtTI7ZmEZhbrxXdGcflIL8sIQxxMo`
- Таблица должна быть открыта для просмотра по ссылке ("Все, у кого есть ссылка" → Читатель)
